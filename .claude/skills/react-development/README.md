# React Development Skill

Covers functional component patterns, custom hooks, composition, and React 18 best practices for the bluekode-lms frontend.

## When to use

- Scaffolding new components or pages
- Refactoring class components or poorly structured JSX
- Reviewing component design for separation of concerns
- Implementing new hooks

## Usage

```
Follow the react-development skill to create a <ComponentName> component.
```
