# Performance Skill

Covers memoization, code splitting, render optimization, and virtualization patterns for the bluekode-lms frontend.

## When to use

- Identifying and fixing unnecessary re-renders
- Adding lazy loading to routes or heavy components
- Optimizing large list rendering
- Reviewing Zustand selectors for over-subscription

## Usage

```
Follow the performance skill to optimize the <ComponentName> component.
```
