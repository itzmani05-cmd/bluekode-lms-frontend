# State Management Skill

Covers Zustand slice design, local vs global state decisions, and selector patterns for the bluekode-lms frontend.

## When to use

- Creating a new Zustand store slice for a feature
- Deciding between local state and global state
- Refactoring prop drilling into a Zustand slice
- Auditing store structure for unnecessary coupling

## Usage

```
Follow the state-management skill to add a <featureName> store slice.
```
