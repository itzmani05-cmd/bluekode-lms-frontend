# Form Validation Skill

Covers Zod schema design, react-hook-form integration, field-level error display, and server error surfacing.

## When to use

- Building a new form with validation
- Adding Zod schemas to an existing unvalidated form
- Surfacing server-side validation errors in the UI
- Reviewing a form for UX and validation completeness

## Usage

```
Follow the form-validation skill to add validation to the <FormName> form.
```
