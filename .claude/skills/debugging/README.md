# Debugging Skill

Systematic approach to diagnosing and fixing bugs in React components, Zustand stores, Axios calls, and TypeScript types.

## When to use

- Tracking down a runtime error or unexpected UI behavior
- Diagnosing a failed API call or malformed response
- Investigating TypeScript compiler errors
- Tracing an unexpected Zustand state mutation

## Usage

```
Follow the debugging skill to investigate <issue description>.
```
