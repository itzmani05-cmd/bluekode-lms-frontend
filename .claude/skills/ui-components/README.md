# UI Components Skill

Covers building reusable, accessible UI components using shadcn/ui primitives and Tailwind CSS for the bluekode-lms design system.

## When to use

- Creating new shared or feature-scoped UI components
- Extending or wrapping shadcn/ui primitives
- Auditing components for reusability and consistency
- Applying mobile-first responsive styles

## Usage

```
Follow the ui-components skill to build a <ComponentName> component.
```
