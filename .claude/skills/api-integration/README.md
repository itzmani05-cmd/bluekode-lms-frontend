# API Integration Skill

Covers typed Axios API modules, the shared Axios instance, interceptors, error handling, and Zod response validation.

## When to use

- Adding a new API module for a feature
- Setting up request/response interceptors
- Handling auth token refresh logic
- Validating API responses with Zod

## Usage

```
Follow the api-integration skill to add API calls for the <featureName> feature.
```
