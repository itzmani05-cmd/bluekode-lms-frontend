# Code Review Skill

Structured review checklist for React + TypeScript components, hooks, stores, and API modules in the bluekode-lms codebase.

## When to use

- Reviewing a PR or a set of changed files
- Self-reviewing before opening a PR
- Auditing a feature slice for standards compliance
- Checking for accessibility, type safety, and performance issues

## Usage

```
Follow the code-review skill to review <file or feature>.
```
